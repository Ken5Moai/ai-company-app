はじめの一手

撮る → 取り込む(AIが題名・キーワード・注意点を付ける) → 書き出して各サイトへ投稿 → 帳簿に記帳。 この4手のうち、2手目と3手目をこのアプリが肩代わりします。
おことわり — 枚数の目安(50 / 200 / 500枚)や金額は、参考にした解説動画で語られた 一例です。売れ方は題材・時期・サイトの審査で大きく変わり、収入を保証するものではありません。 AIが出す「注意点」も下読みで、最終的な判断は各サイトの規約とご自身の責任でお願いします。

テーマを決める

毎日通る場所を書くだけで、AIが「売り物になる切り口」と撮影リストを作ります。 条件は3つ — 週3回以上通る / 時間帯・季節で変わる / 数年で変わりそう。

いま追いかけているテーマ

写真を取り込む

選んだ枚数ぶん、AIが順に見て「日本語の題名 / 英語の題名 / 説明 / キーワード / 掲載の注意点 / 売れやすさ」を付けます。 元の写真はこの端末から出ません(AIに送るのは縮小したコピーだけ)。投稿は元データで行ってください。
