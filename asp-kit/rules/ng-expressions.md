# NG表現リスト(writer は書かない / checker は落とす)

機械で拾えるものは `scripts/check.mjs` にも同じ規則が入っています。
ここを直したら、スクリプトの `RULES` も合わせて直してください。

| 区分 | 例 | なぜダメか | 言い換えの例 |
|---|---|---|---|
| PR表記なし | 冒頭に「広告」「PR」がない | ステルスマーケティング規制(景品表示法の告示・2023年10月施行) | 1行目に「※この記事はアフィリエイト広告(PR)を含みます。」 |
| 断定 | 絶対 / 必ず / 誰でも / 確実に / 100% | 根拠を示せない約束になる | 「〜という人もいます」「〜の場合があります」 |
| 時事 | 最新 / 今月 / 今年 / 今なら / 2026年 | 古くなると誤情報になる | 使わない |
| 最上級 | No.1 / 最安 / 業界一 | 根拠資料なしの最上級表示(景品表示法) | 公式に出典があるときだけ、出典つきで |
| 利益の約束 | 元本保証 / 必ず儲かる / 稼げます | 金融商品取引法・景品表示法 | 「相談で選択肢を整理できます」 |
| 年収・内定の約束 | 年収100万円アップ / 内定確実 | 職業安定法・景品表示法。公式の実績値も条件つき | 公式の数字を使うなら出典と条件を併記 |
| 借入の煽り | 審査なし / 誰でも借りられる | 貸金業法 | 扱わない(`brake.md`) |
| 健康・医療の効果 | 治る / 効く / 痩せる | 薬機法 | 扱わない |
| 体験の捏造 | 相談してみた / 私も登録した(体験がないのに) | 読者を誤認させる | 「公式によると、申し込みの流れは〜」 |
| 根拠のない数字 | 公式にも案件情報にもない「満足度98%」 | 出典のない数値 | 消すか、出典を書く |
| 煽り | 「今すぐ相談しないと損」 | 判断材料にならない | 「迷っている段階でも相談できます」 |
