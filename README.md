# AIカンパニー 実務版

指示ひと言で、AI役員5名(企画・開発・広報・経理・秘書)が
**事業ブリーフ / ランディングページ(HTML) / SNS告知文 / 見積書 / 業務報告書** を生成する単一HTMLアプリ。
あなたの仕事は、押印(決裁)だけ。

## 使い方

1. GitHub Pages の URL(または `index.html` をブラウザで直接)開く
2. 設定 → [platform.claude.com](https://platform.claude.com) で取得した Anthropic API キーを登録 → 接続を確認
3. 社長室で指示を入力 → 執行 → 成果物に押印 → コピー / 保存 / 共有で納品
4. 案件簿で納品・入金を記帳(入金済み合計 = 売上)

APIキーは端末のブラウザ内(localStorage)にのみ保存され、送信先は Anthropic API だけです。
キー未登録の環境ではデモモードで全フローを体験できます。

## 費用の目安

1案件あたり: Claude Opus 4.8 約$0.5〜1.5 / Sonnet 5 約$0.2〜0.6 / Haiku 4.5 $0.1未満

# 光のクロニクル(`rpg.html`)

ドラゴンクエスト風のコマンド戦闘 × ファイナルファンタジー風のサイドビュー隊列を、
**専用UI**(青枠ウィンドウ・ドット絵・チップチューン)で組んだ単一HTMLのRPG。
外部ライブラリ・画像・音声ファイルは一切なし。すべてCanvasとWebAudioで描画・生成しています。

## 遊びかた

`rpg.html` をブラウザで開くだけ(オフラインでも動作)。

| 操作 | キーボード | スマホ |
|---|---|---|
| 移動 | ←↑↓→ / WASD | 画面下の十字キー |
| 決定・調べる・話す | Z / Enter / Space | Aボタン |
| キャンセル・メニュー | X / Esc | Bボタン・メニュー |
| メッセージ送り | Z / Enter / Space | Aボタン・**文章の窓をタップ** |

## 内容

- **5人の仲間** — アレン(勇者)/ ガイ(戦士)/ ミナ(僧侶)/ リノ(魔法使い)、
  そして はての島で出会う ルカ(とうぞく)。戦うのは先頭4人で、
  メニューの「ならびかえ」で入れ替え(ひかえも経験値が半分入ります)
- **フィールド探索** — 世界地図・城・村2つ・自動生成される洞窟2階層・魔王城、
  そして **ふねで渡る はての島**(星降りの神殿)
- **モンスター28種** — どの地域でも十数通りの組み合わせで出現。
  にげ足の速い メタルライム、色ちがいの上位種、状態異常を使う敵など
- **モンスターずかん** — 出会うと記録され、絵と能力値、たおした数を確認できます
- **ターン制コマンド戦闘** — たたかう / じゅもん・とくぎ / どうぐ / ぼうぎょ / にげる、
  すばやさ順の行動、会心の一撃、どく・ねむり、呪文エフェクトとダメージ表示
- **じゅもん・とくぎ 全54種** — レベルアップで習得
  - 攻撃: メザ〜メザゾーマ / ヒャト〜マヒャト / バキ〜バキクロス / エオ〜エオナズン /
    ライデオン・ギガデオン / ドルバ系 / ドレイン(HP吸収) / マホドラ(MP吸収) / ザギ・ザラギ(即死)
  - 回復: ホイム〜ベホナ / ベホナラー(全体) / ザオラム・ザオリグ(蘇生) / キアリア・キアリグ
  - 補助: スガラ・スクルド・バイキルド・ピオリン / フバーラ(ブレス軽減) / マジックバリヤ(呪文軽減)
  - 弱体: ルガニ(守備down) / ヘナドス(攻撃down) / マヌーザ(幻惑) / マホドーン(呪文封じ) / ラリボー系
  - 移動: ルーナ(町へ) / リレミド(ダンジョン脱出) / トヘロズ(130歩の魔よけ)
  - とくぎ(MP不要): ためる / みだれぎり / まわしげり / かぶとわり / おたけび(ひるませる) /
    しんくうぎり / かばう / せいけんづき / すてみ
  - とうぞくのとくぎ: なげナイフ / あしばらい / しのびあし / ぬすむ /
    きゅうしょづき / とんずら / はやぶさぎり / つじぎり
- **装備の見た目** — 武器と よろいが ドット絵に反映されます(剣・斧・つえ・こん棒、
  よろいの色。ほのおのつるぎ や ひかりのつるぎ は光ります)
- **町の施設** — 道具屋・武器防具屋(装備の増減値プレビュー付き)・宿屋・教会
- **物語** — 風の洞窟でゴーレムを倒し「かぜのオーブ」を入手 → 魔王城の結界を破り、
  魔王ザルドスを討つ。エンディングとスタッフロールあり
- **セーブ** — 教会・女神像・メニューの「きろく」から保存。
  **ぼうけんの書は3つ**あるので、ひとつの端末を何人かで使っても記録が混ざりません
  (別々の端末で開いた場合は、そもそも記録は端末ごとに分かれます)
- **ふっかつのじゅもん** — セーブ内容を文字列として書き出し / 読み込みできます。
  端末を変えるとき、ブラウザの記録が消えたとき、記録を保存できない環境でも再開できます
  (メニュー →「きろく」、またはタイトル画面から)

クリアまでの目安は 40〜60分(戦闘およそ100回、推奨レベル 24〜26)。
はての島は とくに手ごわいので、ある程度 育ててから 渡ることをおすすめします。

# まもりの砦(`td.html`)

「光のクロニクル」外伝のタワーディフェンス。魔王亡きあとの残党が
アルシア城へ押し寄せる。街道ぞいに**なかま5人を配置して20の波をしのぐ**。
本編と同じドット絵・ウィンドウUI・チップチューンをそのまま使っています。

## 遊びかた

`td.html` をブラウザで開くだけ(オフラインでも動作)。

- 下のカードで**なかまを選び**、草地のマスを**タップ／クリック**して配置
- 配置ずみのなかまをタップすると**強化(Lv3まで)**か**売却**
- 「つぎの波」で早出しするとボーナス、「×1 / ×2」で倍速
- メッセージは**文章の窓をタップ**すると先へ進みます
- キーボードは ←↑↓→ でマス選択、Z で決定、X で取り消し

## 5人の役わり

| なかま | 費用 | 特徴 |
|---|---|---|
| アレン | 70G | バランス型。まず1人めに |
| ルカ | 80G | 手数が多く、倒すたびゴールドを盗む |
| ガイ | 115G | 遅いが一撃が重く、まとめてなぎ払う |
| ミナ | 95G | 攻撃しない。まわりの砦を速め、敵の足を止める |
| リノ | 150G | 遠くまで届き、かたい敵にも効く魔法 |

物理攻撃は敵の守備で軽くなりますが、リノの魔法は素通しします。
1種類だけを並べても20波は防げません(実測: アレンのみ→11波、ミナ抜き→16波で落城)。

敵はモンスター28種がそのまま登場し、5・10・15・20波はボス。
にげ足の速いメタルライムを倒せれば大きな稼ぎになります。

# 巨獣狩り(`hunt.html`)

モンスターハンター風の**アクション狩猟ゲーム**。巨獣と一対一で渡りあい、
素材を剥ぎ取って装備をきたえ、また次の獣へ向かう。
本編と同じドット絵・チップチューン・窓UIを、革と骨の色に着替えて使っています。

## 遊びかた

`hunt.html` をブラウザで開くだけ(オフラインでも動作)。

| 操作 | キーボード | スマホ |
|---|---|---|
| 移動 | WASD / ←↑↓→ | 左スティック |
| ダッシュ | Shift | スティックを深く倒す |
| 攻撃 | Z | 斬 |
| 溜め攻撃(長おし) | X | 溜 |
| 回避(前転) | C / Space | 避 |
| 道具を使う | Q | 具 |
| 道具を持ちかえる | E | 替 |
| 抜刀 / 納刀 | V | — |

メッセージは文章の窓をタップでも進みます。

## 芯にあるもの

- **回避と体力の駆け引き** — 前転には無敵時間があり、スタミナを22消費します。
  転がってばかりでは息が切れ、殴ってばかりでは轢かれる
- **攻撃は置きにいくもの** — どの技も 振りかぶり → 判定 → 戻り の3段。
  出したら止まれないので、獣の隙を読んでから振る
- **切れ味** — 斬るたびに落ち、赤まで落ちるとかたい部位に**弾かれて**大きな隙。
  砥石で研ぐあいだは完全に無防備
- **部位ごとの効き** — 頭・胴・尻尾・翼・岩殻で通りがまるで違う。
  ヌシの背甲は白い切れ味でなければ通らず、腹だけがつけ入る隙
- **部位破壊と尻尾切断** — こわすと素材が増え、翼を折れば飛べなくなる
- **獣の状態** — 怒り(速く・重く)/ 疲労(よだれ・鈍る)/ 気絶(ハンマーで頭を殴り続ける)/
  瀕死(足を引きずり、巣へ帰って眠る)。眠っている獣への一撃は3倍
- **生け捕り** — 瀕死の獣を落とし穴にかけ、麻酔玉を2つ。討伐より報酬が多い
- **力尽きるのは3回まで**。3回目で狩猟失敗

## 4つの武器

| 武器 | 持ち味 |
|---|---|
| 大剣 | 遅いが一撃が別格。3段階の溜め斬り。動けない時間が長い |
| 片手剣 | 手数と小回り。3連コンボ。**抜いたまま道具が使える** |
| ハンマー | 打撃。頭を殴り続けると**気絶**させられる。尻尾は切れない |
| 弓 | 間合いの外から。溜め3段、最大溜めは3本同時。安全だがやや時間がかかる |

それぞれ4段階まで強化でき、上位ほど切れ味の上限(緑→青→白)が上がります。

## 巨獣4種

| 獣 | 特徴 |
|---|---|
| ドスガロ | 群れの長。噛みつき・突進・三連噛み。まずはここから |
| イワトビゴウ | 背の岩殻が刃を弾く。転がり突進と岩投げ。腹か頭を狙う |
| エンビガラス | 空から襲う。火炎ブレスと滑空突進。翼を折れば地に落ちる |
| ヌシ・ガンドウ | 谷のヌシ。咆哮でひるませ、地割れと大尾でなぎ払う |

討伐の目安は 適正装備で 2〜4分(ヌシは 3〜4分半)。
装備が足りないと同じ獣に5分以上かかります。

## 記録

自動保存に加えて、メニューの「きろく」から**あいことば**(セーブ文字列)を
書き出し / 読みこみできます。端末を変えるときや、記録を保存できない環境でも再開できます。
