# AIカンパニー 実務版

指示ひと言で、AI役員5名(企画・開発・広報・経理・秘書)が
**事業ブリーフ / ランディングページ(HTML) / SNS告知文 / 見積書 / 業務報告書** を生成する単一HTMLアプリ。
あなたの仕事は、押印(決裁)だけ。

## 使い方

1. GitHub Pages の URL(または `index.html` をブラウザで直接)開く
2. 設定 → [platform.claude.com](https://platform.claude.com) で取得した Anthropic API キーを登録 → 接続を確認
3. 社長室で指示を入力 → 執行 → 成果物に押印 → コピー / 保存 / 共有で納品
4. 案件簿で納品・入金を記帳(入金済み合計 = 売上)

APIキーは端末のブラウザ内(localStorage)にのみ保存され、送信先は Anthropic API だけです。
キー未登録の環境ではデモモードで全フローを体験できます。

## 費用の目安

1案件あたり: Claude Opus 4.8 約$0.5〜1.5 / Sonnet 5 約$0.2〜0.6 / Haiku 4.5 $0.1未満

# 光のクロニクル(`rpg.html`)

ドラゴンクエスト風のコマンド戦闘 × ファイナルファンタジー風のサイドビュー隊列を、
**専用UI**(青枠ウィンドウ・ドット絵・チップチューン)で組んだ単一HTMLのRPG。
外部ライブラリ・画像・音声ファイルは一切なし。すべてCanvasとWebAudioで描画・生成しています。

## 遊びかた

`rpg.html` をブラウザで開くだけ(オフラインでも動作)。

| 操作 | キーボード | スマホ |
|---|---|---|
| 移動 | ←↑↓→ / WASD | 画面下の十字キー |
| 決定・調べる・話す | Z / Enter / Space | Aボタン |
| キャンセル・メニュー | X / Esc | Bボタン・メニュー |
| メッセージ送り | Z / Enter / Space | Aボタン・**文章の窓をタップ** |

  メニューの「ならびかえ」で入れ替え(ひかえも経験値が半分入ります)

  そして **ふねで渡る はての島**(星降りの神殿)

- **モンスターずかん** — 出会うと記録され、絵と能力値、たおした数を確認できます
- **ターン制コマンド戦闘** — たたかう / じゅもん・とくぎ / どうぐ / ぼうぎょ / にげる、
  すばやさ順の行動、会心の一撃、どく・ねむり、呪文エフェクトとダメージ表示

  - 移動: ルーナ(町へ) / リレミド(ダンジョン脱出) / トヘロズ(130歩の魔よけ)

# まもりの砦(`td.html`)

「光のクロニクル」外伝のタワーディフェンス。魔王亡きあとの残党が
アルシア城へ押し寄せる。街道ぞいに**なかま5人を配置して20の波をしのぐ**。
本編と同じドット絵・ウィンドウUI・チップチューンをそのまま使っています。

## 遊びかた

`td.html` をブラウザで開くだけ(オフラインでも動作)。

- 下のカードで**なかまを選び**、草地のマスを**タップ／クリック**して配置
- 配置ずみのなかまをタップすると**強化(Lv3まで)**か**売却**
- 「つぎの波」で早出しするとボーナス、「×1 / ×2」で倍速
- メッセージは**文章の窓をタップ**すると先へ進みます
- キーボードは ←↑↓→ でマス選択、Z で決定、X で取り消し

## 5人の役わり

| なかま | 費用 | 特徴 |
|---|---|---|
| アレン | 70G | バランス型。まず1人めに |
| ルカ | 80G | 手数が多く、倒すたびゴールドを盗む |
| ガイ | 115G | 遅いが一撃が重く、まとめてなぎ払う |
| ミナ | 95G | 攻撃しない。まわりの砦を速め、敵の足を止める |
| リノ | 150G | 遠くまで届き、かたい敵にも効く魔法 |

物理攻撃は敵の守備で軽くなりますが、リノの魔法は素通しします。
1種類だけを並べても20波は防げません(実測: アレンのみ→11波、ミナ抜き→16波で落城)。

敵はモンスター28種がそのまま登場し、5・10・15・20波はボス。
にげ足の速いメタルライムを倒せれば大きな稼ぎになります。

# 巨獣狩り(`hunt.html`)

モンスターハンター風の**アクション狩猟ゲーム**。巨獣と一対一で渡りあい、
素材を剥ぎ取って装備をきたえ、また次の獣へ向かう。
本編と同じドット絵・チップチューン・窓UIを、革と骨の色に着替えて使っています。

## 遊びかた

`hunt.html` をブラウザで開くだけ(オフラインでも動作)。

| 操作 | キーボード | スマホ |
|---|---|---|
| 移動 | WASD / ←↑↓→ | 左スティック |
| ダッシュ | Shift | スティックを深く倒す |
| 攻撃 | Z | 斬 |
| 溜め攻撃(長おし) | X | 溜 |
| 回避(前転) | C / Space | 避 |
| 道具を使う | Q | 具 |
| 道具を持ちかえる | E | 替 |
| 抜刀 / 納刀 | V | — |

メッセージは文章の窓をタップでも進みます。

## 芯にあるもの

- **回避と体力の駆け引き** — 前転には無敵時間があり、スタミナを22消費します。
  転がってばかりでは息が切れ、殴ってばかりでは轢かれる
- **攻撃は置きにいくもの** — どの技も 振りかぶり → 判定 → 戻り の3段。
  出したら止まれないので、獣の隙を読んでから振る
- **切れ味** — 斬るたびに落ち、赤まで落ちるとかたい部位に**弾かれて**大きな隙。
  砥石で研ぐあいだは完全に無防備
- **部位ごとの効き** — 頭・胴・尻尾・翼・岩殻で通りがまるで違う。
  ヌシの背甲は白い切れ味でなければ通らず、腹だけがつけ入る隙
- **部位破壊と尻尾切断** — こわすと素材が増え、翼を折れば飛べなくなる
- **獣の状態** — 怒り(速く・重く)/ 疲労(よだれ・鈍る)/ 気絶(ハンマーで頭を殴り続ける)/
  瀕死(足を引きずり、巣へ帰って眠る)。眠っている獣への一撃は3倍
- **生け捕り** — 瀕死の獣を落とし穴にかけ、麻酔玉を2つ。討伐より報酬が多い
- **力尽きるのは3回まで**。3回目で狩猟失敗

## 4つの武器

| 武器 | 持ち味 |
|---|---|
| 大剣 | 遅いが一撃が別格。3段階の溜め斬り。動けない時間が長い |
| 片手剣 | 手数と小回り。3連コンボ。**抜いたまま道具が使える** |
| ハンマー | 打撃。頭を殴り続けると**気絶**させられる。尻尾は切れない |
| 弓 | 間合いの外から。溜め3段、最大溜めは3本同時。安全だがやや時間がかかる |

それぞれ4段階まで強化でき、上位ほど切れ味の上限(緑→青→白)が上がります。

## 巨獣4種

| 獣 | 特徴 |
|---|---|
| ドスガロ | 群れの長。噛みつき・突進・三連噛み。まずはここから |
| イワトビゴウ | 背の岩殻が刃を弾く。転がり突進と岩投げ。腹か頭を狙う |
| エンビガラス | 空から襲う。火炎ブレスと滑空突進。翼を折れば地に落ちる |
| ヌシ・ガンドウ | 谷のヌシ。咆哮でひるませ、地割れと大尾でなぎ払う |

討伐の目安は 適正装備で 2〜4分(ヌシは 3〜4分半)。
装備が足りないと同じ獣に5分以上かかります。

## 記録

自動保存に加えて、メニューの「きろく」から**あいことば**(セーブ文字列)を
書き出し / 読みこみできます。端末を変えるときや、記録を保存できない環境でも再開できます。

# まちの記録係(`photo.html`)

通勤路や地元の日常風景をスマホで撮り、ストックフォト(PIXTA・写真AC・Adobe Stock・Shutterstock)に
並べていくための**台帳**。写真副業の手順は4手ありますが、そのうち手間の大半を占める
**②値付け(題名・キーワード・掲載の注意点)**と**③投稿の下ごしらえ**をAIに肩代わりさせます。

`photo.html` をブラウザで開くだけ(スマホ前提・オフラインでも台帳として動作)。

## 4手のうち、どこが半自動になるか

| 手順 | 人がやること | このアプリがやること |
|---|---|---|
| ① 撮る | 通勤路で1枚撮る | テーマを決め、**今日撮るカット**を毎日1つ出す |
| ② 値付け | 写真を選ぶだけ | 1枚ずつAIが見て、日本語/英語の題名・説明・キーワード20〜40語・**掲載の注意点**・売れ見込みを付ける |
| ③ 投稿 | 各サイトに元データをアップ | サイト別に文言をコピー、Adobe Stock / Shutterstock は**CSVで一括書き出し** |
| ④ 記帳 | 売れた額を入力 | 月ごとの推移・サイト別累計・AI利用料を差し引いた収支 |

## 5つの画面

- **記録** — きょうの一枚 / 手持ち・値付け済・投稿済・公開中の数 / 50・200・500枚の積み上げ / 撮った日の連続記録
- **撮る** — 通り道を書くと、AIが「続けられて売れるテーマ」を3つと撮影カットを提案。
  条件は動画と同じ3つ(**週3回以上通る / 時間帯・季節で変わる / 数年で変わりそう**)
- **仕分け** — スマホの写真をまとめて選ぶと、順番に値付けしていく。中身はあとから直せます
- **台帳** — 値付け待ち・要注意・投稿できる・投稿済・公開中で絞り込み。投稿モードとCSV書き出し
- **帳簿** — 月ごとの売上を記帳。棒グラフと、サイト別の累計・投稿枚数

## 掲載前の「注意点」

AIは値付けと同時に、顔が判別できる人物・車のナンバー・店名やロゴ・他人の著作物・私有地といった
**そのままでは出せない要素**を拾い、対処(ぼかす / 撮り直す / 報道用途に限定する)を添えます。
**高**が付いた写真は投稿モードに出てきません。ただしこれは下読みで、最終判断は各サイトの規約と
ご自身の責任でお願いします。

## 費用の目安

値付け1枚あたり Opus 5 約5〜6円 / Sonnet 5 約3円 / Haiku 4.5 約1円(いずれも概算・設定で切り替え)。
100枚で数百円ほど、Haiku なら100円ほどです。実際の利用額は帳簿と設定に概算が出ます。

## おことわり

APIキーは端末のブラウザ内(localStorage)にのみ保存され、送信先は Anthropic API だけです。
写真は IndexedDB に**縮小したものだけ**が残り、AIに送るのも縮小したコピーです(投稿は元データで)。
キー未登録の環境では見本モードで全フローを試せます。

枚数の目安(50 / 200 / 500枚)や金額は、参考にした解説動画で語られた**一例**です。
売れ方は題材・時期・各サイトの審査で大きく変わり、収入を保証するものではありません。

# うごく判子(`sticker.html`)

**動くLINEスタンプ**を1セット24個ぶん仕立てるための工房。
作り方そのものは単純でも、24個ぶんの規格合わせが途方もなく面倒です。
このアプリは、そのうち機械にできるところを全部引き受けます。

`sticker.html` をブラウザで開くだけ。**動画も画像も、どこにも送りません。**

## 六つの工程のうち、どこが機械になるか

| 工程 | 人がやること | このアプリがやること |
|---|---|---|
| 一 キャラクターシート | 特徴を書く | 画像生成AIへの注文書を日本語/英語で組み立てる |
| 二 動きを60個 | 眺めて外す | 毎日の返事に使える動きと言葉を60組ならべる |
| 三 動画の台本 | 動画生成AIに渡す | 緑背景・カメラ固定・10カット×1.5秒の指示を6本ぶん |
| 四 緑を抜いて変換 | 動画を選ぶ | 抜き・穴つぶし・**文字の焼き込み**・規格に収まるAPNGへ一括変換 |
| 五 24個を選ぶ | **タップで選ぶ** | 動いたまま一覧、並び順の自動整列 |
| 六 申請の一式 | zipを出す | main・tab・01〜24を作り、規格を点検して zip に |

## 可愛さは、描き込みの多さではなく省き方で決まる

売れているスタンプを並べて見ると、可愛さの作り方はかなりはっきりしています。
工程一の注文書と工程三の台本には、その省き方をそのまま書き下してあります。

- 目は**黒い点をふたつ**。白目も瞳孔も光の点も描かない。左右に大きく離す
- 顔の部品は**顔の下半分に寄せる**(幼く見える)
- 口は小さく、鼻は描かない。ほおに丸いチーク
- 輪郭線は**太さを変えない**。ほんの少し震える手描きの線
- **平塗り**。影・ぼかし・光沢を入れない。色は3〜4色まで
- 手は**ミトン**。指を描き分けない
- 左右を完璧な対称にしない

動画生成でいちばん崩れるのが目と指なので、台本にも
「目は点のまま」「指を描き分けない」「感情は口とほおと手足で作る」を毎回書き込みます。

## 文字を焼き込む

人気のスタンプはほとんどが文字入りで、しかも**縦書きが多い**。
このアプリは、動きの名前をそのまま言葉として持っていて(「ありがとう」「ちょいまち」「ムリ〜」…)、
変換のときに絵の横へ縦書きで焼き込みます。白フチ付きなので、濃い背景の会話でも読めます。

文字を入れると台紙は320×270にそろい、絵は文字のない側へ自動で寄ります。
**文字なしにも切り替えられます** — 記事の書き手は文字なしで海外比率2割を取っていて、
文字がなければタイや台湾の会話でもそのまま使えます。どちらの作り方も選べます。

## 規格まわりは全部ここで弾く

APNG(拡張子は `.png`)/ 最大320×270 / 5〜20コマ /
再生時間はループ込みで**1・2・3・4秒ちょうど** / 1ファイル**300KB以下** / 背景透過 —
どれも変換のたびに満たすよう追い込み、zipを作るときにもう一度数え直します。

とくに気をつけているのが、審査で弾かれやすい
**「イラストの内部が透過されています」**。
緑を抜くとキャラの内側にも目に見えない小さな穴が残ることがあるので、
*外周からたどり着けない透明*を探して埋め、
穴のふちに残る緑を種にしないよう2画素ぶん内側から色を借りて塗り直します。
書き出したファイルを読み直して数え直すところまでやります。

## 中で動いているもの

外部ライブラリは一切使っていません。PNG/APNGの書き出しと読み込み、
グリーンバックの抜き、透明度を保ったままの拡大縮小、減色、ZIPの組み立てまで、
すべてこの1ファイルの中にあります。

- **APNG書き出し** — 差分矩形・適応フィルタ・全コマ共通パレット。圧縮は `CompressionStream`
- **APNG読み込み** — 選び終わってから main.png(240×240)や tab.png を作り直すため
- **減色** — 透明・半透明・不透明を混ぜずに量子化(混ぜると内部透過の事故になります)
- **穴の埋め方** — 平塗りの絵なので色を平均しない(白と紺の境目が灰色の痣になります)
- **文字** — 絵とは別の層。「口」のような字の内側は当然すいているので、絵の欠けとは分けて数えます

## 費用の目安

工程一〜三でAIを使う場合のみ。1セットあたり Opus 5 で数十円ほどです。
工程四〜六はAPIを使わないので無料です。
APIキーを登録しなくても、備え付けの動き60個でそのまま最後まで進められます。
