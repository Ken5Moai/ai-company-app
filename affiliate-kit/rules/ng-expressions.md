# NG表現リスト(writer は書かない / checker は落とす)

機械で拾えるものは `scripts/check.mjs` にも同じ規則が入っています。
ここを直したら、スクリプトの `RULES` も合わせて直してください。

| 区分 | 例 | なぜダメか | 言い換えの例 |
|---|---|---|---|
| PR表記なし | 冒頭に「広告」「PR」がない | ステルスマーケティング規制(景品表示法の告示・2023年10月施行) | 1行目に「※この記事はアフィリエイト広告(PR)を含みます。」 |
| 断定 | 絶対 / 必ず / 誰でも / 確実に / 100% / 間違いなく | 根拠を示せない約束になる | 「多くのレビューで」「〜という声が目立ちます」 |
| 時事 | 最新 / 今月 / 今年 / 今なら / 期間限定 / 2026年 | 古くなると誤情報になる | 使わない。必要なら「記事作成時点」と書き日付を明記 |
| 最上級・優良誤認 | No.1 / 最安 / 日本一 / 業界一 / 一番売れている | 根拠資料なしの最上級表示(景品表示法) | 「〜を重視する人には候補になります」 |
| 健康・医療の効果 | 治る / 治療 / 効く / 痩せる / 腰痛が消える / 歯周病を防ぐ | 医療効果の標ぼう(薬機法)。マットレス・電動歯ブラシで特に起きやすい | 「寝心地の好みが分かれます」「磨き心地についての声」 |
| 体験の捏造(未使用時) | 使ってみた / 愛用 / 我が家では / 私も買いました | 読者を誤認させる。使っていないなら書かない | 「レビューでは〜という声がありました」 |
| 根拠のない数字 | レビューにも商品情報にもない「30%」「8時間」 | 出典のない数値 | 数字を消すか、公式で確かめて出典を書く |
| 転載 | レビュー本文の20字超の丸写し、投稿者名 | 著作権・販売サイトの規約・個人情報 | 要約して言い換える |
| 煽り | 「買うと後悔します」「知らないと損」 | 判断材料にならない | 「〜な人には向かない、という声が多い」 |

ジャンル別に足したいNG表現は、この表の下に追記してください。
